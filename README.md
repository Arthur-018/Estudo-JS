
# 📘 Estudo-JS

Este repositório é dedicado **exclusivamente ao meu estudo de JavaScript**.  
Aqui registro exercícios, práticas e códigos feitos durante aulas e treinamentos, com o objetivo de aprender e evoluir na linguagem.

---

## 🎯 Objetivo

- Aprender JavaScript do básico ao intermediário
- Praticar lógica de programação
- Fixar conceitos por meio de exercícios e exemplos
- Ter um histórico organizado da minha evolução

---

## 📚 Conteúdos Estudados

- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais (`if`, `else`, `switch`)
- Laços de repetição (`for`, `while`)
- Funções
- Arrays e objetos
- Manipulação básica do DOM
- Eventos em JavaScript

*(Os conteúdos podem aumentar conforme o estudo evolui)*

- JavaScript
